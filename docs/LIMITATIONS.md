# Limitations

This repository is for data engineering, statistical exploration, and backtesting practice.

## Randomness boundary

福彩3D results are high-randomness events. Historical structure can be summarized, but historical summaries do not imply reliable future prediction.

## Backtest boundary

Walk-forward testing is useful because it avoids some obvious look-ahead mistakes, but it still has limits:

- parameter choices can overfit validation periods;
- public historical draws are only one realized random path;
- structural targets such as sum, span, and repeat type are much easier than exact-number targets;
- a short-term metric above a random baseline can disappear in a later window;
- payout, cost, and bankroll risk are outside the scope of this research archive.

## Forecast artifact boundary

`forecast_next7days_entertainment.*` is generated by recursive simulation. From day 2 onward, it uses the previous simulated primary pick to update the rolling context. That makes later days increasingly synthetic.

Use it only as an entertainment example of the pipeline output format.

## Responsible-use boundary

Do not treat any output in this repository as certainty or as a strategy. If wording appears to imply certainty, treat that as a documentation bug and fix it.
