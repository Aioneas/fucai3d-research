# 福彩3D最新开奖结果

当用户要查询最近一次中国福利彩票3D开奖结果时：

1. 优先使用 browser 工具访问：
   `https://www.cwl.gov.cn/cwl_admin/front/cwlkj/search/kjxx/findDrawNotice?name=3d&issueCount=&issueStart=&issueEnd=&dayStart=&dayEnd=&pageNo=1&pageSize=5&week=&systemType=PC`
2. 读取页面中的 JSON 文本并解析 `result` 数组
3. 默认取 `result[0]` 作为最新一期，并提取：
   - `code` → 期号
   - `date` → 开奖日期（去掉括号内星期，整理为 `YYYY-MM-DD`）
   - `red` → 开奖号码（如 `8,7,0`，输出时转成 `8 7 0`）
4. 如果用户要求“更新结果”“补落下的”“核对最近几期”或怀疑数字有误：
   - 不要只看最新一期
   - 必须至少读取最近 3~5 期（可通过 `pageSize=5` 或更大）
   - 逐期核对 `code / date / red`
   - 如本地历史缺失期号，要一并补录；如已有错误号码，要按官方接口修正
5. 只有在官方接口不可用时，才退回中国福彩网网页正文或其他权威来源，并明确说明数据来源
6. 注意：在当前设备上，shell 直接 `curl/wget` 这个接口可能返回 403；优先使用 browser 会话访问与读取，不要默认依赖 shell 直连

拿到结果后，额外执行娱乐功能：

1. 使用 `/var/minis/shared/fucai3d/recommender.py update ISSUE DATE DIGITS` 把本次开奖结果写入历史记录 `/var/minis/shared/fucai3d/history.json`
2. 如果发现有缺失期号，要把缺失的几期一并补录；如果发现历史里已有错误号码，要以最新核对结果修正本地历史
3. 使用 `/var/minis/shared/fucai3d/recommender.py bundle 5` 生成：
   - 基础娱乐推荐 5 组
   - 冷号偏好推荐 3 组
   - 热号混合推荐 3 组
   - 最近窗口内的 0~9 出现频率
   - 热号 / 冷号摘要
4. 明确说明这些建议号码只是基于历史排除规则与简单频率偏好生成的“玩具推荐”，不代表真实预测能力

输出尽量简洁，默认格式：

- 期号：第XXXXXXX期
- 开奖日期：YYYY-MM-DD
- 开奖号码：X X X
- 历史记录：已更新 / 已存在 / 已纠错
- 如有补录：已补录第XXXXXXX期、第XXXXXXX期...
- 娱乐推荐：A B C / D E F / ...
- 冷号偏好：A B C / D E F / ...
- 热号混合：A B C / D E F / ...
- 近30期热号：x, x, x...
- 近30期冷号：x, x, x...
- 说明：仅基于历史记录做简单排除与频率统计，不构成预测建议

推荐逻辑说明（无需向用户展开太多）：

- 优先避开近期已出现的完全相同三位数组合
- 尽量避开近期相同和值
- 尽量避开近期相邻两位重复模式
- 使用最近窗口统计冷热号频率
- 如果历史太少或约束太强，则退化为随机补足

如果官方接口无法直接给出开奖号码：

1. 先尝试打开中国福彩网对应详情页或开奖栏目正文
2. 优先继续使用中国福彩网官方页面中的近期开奖信息做核对
3. 如仍失败，再改查其他权威来源
4. 明确说明数据来源

如果查询到的信息可能不是最新一期，要明确提示“基于当前官方接口/当前搜索结果”。
